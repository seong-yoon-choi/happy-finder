해피파인더 리디자인 보고서
작성일: 2026-05-05

1. 전체 방향

해피파인더는 기존의 "행복 리스트에서 행복을 찾고 스탬프를 찍는 앱"에서
"행복 리스트를 바탕으로 자유롭게 기록하고, AI가 사용자의 행복 패턴을 분석해주는 앱"으로 전환한다.

핵심 방향은 다음과 같다.

- 행복 리스트는 유지한다.
- 스탬프와 행복을 찾은 횟수 중심의 구조는 제거한다.
- 행복을 이어가는 기준은 "기록"으로 바꾼다.
- 카테고리(소확행, 기분전환, 제대로)는 사용자 화면에서 제거한다.
- 홈, 기록, 분석, 프로필 4개 영역으로 재구성한다.
- AI는 사용자의 기록을 대신 쓰는 기능이 아니라, 기록을 정리하고 분석하고 추천하는 보조 기능으로 사용한다.


2. 앱 구조

최종 탭 구조는 다음을 추천한다.

홈
- 행복 리스트가 보이는 메인 화면
- 카테고리 없이 전체 리스트 표시
- 검색과 태그 필터 제공
- 각 행복 항목에서 바로 기록하기 가능
- 기존 즐겨찾기 기능은 "내 행복"으로 이름을 바꿔 유지
- "내 행복" 위치는 기존 즐겨찾기 하트가 있던 자리를 그대로 사용
- 홈 화면에 플러스 버튼을 추가해 "내 행복 만들기"를 바로 실행 가능하게 함

기록
- 사용자가 남긴 행복 기록을 모아보는 화면
- 리스트에서 기록한 행복 기록 표시
- 리스트와 연결되지 않은 자유 기록 작성 가능
- 짧은 기록, 긴 일기, 사진 기록 모두 허용
- 기록 작성 보조 AI는 기록마다 켜고 끌 수 있음

분석
- AI가 사용자의 기록을 분석하는 화면
- 분석 AI는 서비스 기본 기능으로 항상 켜져 있음
- 분석 데이터 사용은 최초 이용약관/개인정보 동의에 포함
- 최근 행복 유형 비중 표시
- 자주 등장하는 태그 표시
- 최근 행복 패턴 요약
- 앞으로 시도해볼 행복 추천
- 원형 그래프로 행복 유형 비중 시각화

프로필
- 내 행복 항목만 표시
- 내가 만든 행복 항목 표시
- 내 행복 만들기 기능 유지
- 계정, 설정, 알림, AI 기본 사용 여부 관리
- 기존 "찾은 행복 횟수" 중심 UI는 제거
- 즐겨찾기와 만든 행복 수량은 중앙 선택 탭에서만 표시하고, 상단 프로필 카드에서는 중복 표시하지 않는다.
- 추후 분석 기능이 들어오면 상단 프로필 카드의 빈 공간에는 AI가 요약한 "나의 행복 스타일" 정보를 넣는다.
- 예: "나는 혼자 회복하는 감각형 행복 스타일입니다"처럼 사용자를 설명하는 아이콘과 짧은 문장을 표시한다.
- 자세한 내용은 "분석 화면으로 이동" 버튼을 통해 분석 탭에서 확인하도록 연결한다.


3. 홈 / 리스트 MVP

홈은 단순하고 바로 행동할 수 있어야 한다.

기존 제거 대상:
- 소확행 / 기분전환 / 제대로 카테고리 탭
- 길게 눌러 행복을 찾는 기능
- 스탬프 기능
- 행복을 찾은 횟수 표시
- 필요 없어진 연필 버튼

새 카드 구조 예시:

[행복 제목]
[짧은 설명]
[기록하기] [하트 아이콘: 내 행복]

내 행복 추가는 기존 즐겨찾기 하트 아이콘 위치를 그대로 사용한다.
기존 즐겨찾기 기능을 내부적으로 그대로 사용하되, 사용자에게는 "내 행복"으로 표현한다.
즉, 별도의 새 버튼을 늘리기보다 기존 즐겨찾기 자리를 "내 행복"으로 재해석한다.

홈 화면 플러스 버튼:
- 홈 상단 또는 하단 우측에 플러스 버튼을 둔다.
- 플러스 버튼을 누르면 "내 행복 만들기" 화면을 연다.
- 이 기능은 프로필의 "내 행복 만들기"와 같은 기능을 공유한다.
- 사용자는 홈에서 리스트를 보다가 바로 자신만의 행복 항목을 추가할 수 있다.

프로필의 내 행복 영역:
- 내가 내 행복으로 추가한 항목을 보여준다.
- 내가 직접 만든 행복 항목을 보여준다.
- "내 행복 만들기" 버튼은 프로필에도 유지한다.
- 프로필은 내 행복을 관리하는 공간으로 남긴다.


4. 기록 기능

기록 기능은 앱의 새로운 중심이 된다.
기록은 짧은 메모로 제한하지 않는다.
사용자는 한 줄만 남겨도 되고, 긴 일기를 써도 되고, 사진만 남겨도 된다.

기록 유형:
- 리스트 항목과 연결된 기록
- 리스트와 연결되지 않은 자유 기록

자유 기록의 목적:
- 오늘 하루에 대한 자유로운 일기
- 리스트에 없는 행복 기록
- 감정, 생각, 사진, 회고를 부담 없이 남기는 공간

기록 작성 화면 추천:

오늘 어떤 순간을 남기고 싶나요?

[자유 입력 영역]
한 줄이어도 좋고 길게 써도 좋아요.

[사진 추가]
[카메라] [앨범]

기록 AI 도움 [켜짐/꺼짐]

기록 AI 켜짐일 때:
- 한 줄 정리
- 사용자에게 보이는 태그 추천
- 관련 행복 리스트 추천
- 다음 질문 제안

기록 AI 꺼짐일 때:
- 작성 중 추천, 질문, 한 줄 정리 같은 보조 기능을 제공하지 않음
- 사용자는 아무 제안 없이 자유롭게 기록함
- 단, 저장된 기록은 서비스 기본 분석 AI의 분석 데이터로 사용될 수 있음
- 이 분석 데이터 사용은 최초 이용약관/개인정보 동의에서 안내하고 동의받음


5. AI 사용 원칙

AI는 두 종류로 나눈다.

1. 분석 AI
- 앱의 핵심 기능이다.
- 사용자의 저장된 기록과 리스트 사용 데이터를 바탕으로 행복 유형, 태그, 패턴, 추천을 만든다.
- 항상 켜져 있는 상태로 본다.
- 별도의 기록별 토글 대상이 아니다.
- 최초 이용약관/개인정보 동의에서 분석 데이터 사용을 명확히 안내하고 동의받는다.
- 홈, 기록, 분석 등 필요한 기능은 항상 분석 AI가 만든 데이터를 참조할 수 있다.

2. 기록 AI
- 기록 작성 보조 기능이다.
- 사용자가 자유 기록을 작성할 때 추천, 질문, 한 줄 정리, 태그 추천을 제공한다.
- 사용자가 기록마다 켜고 끌 수 있다.
- 끄면 작성 중에는 아무 제안 없이 순수하게 기록만 남긴다.
- 기록 AI를 끄는 것은 분석 AI를 끄는 것이 아니다.

AI 사용 원칙:
- 앱에서 AI API를 직접 호출하지 않는다.
- 모바일 앱은 Supabase Edge Function 또는 별도 서버를 호출한다.
- 서버에서 AI API를 호출한다.
- API 키는 앱에 포함하지 않는다.
- 기록 AI 결과는 제안이며, 사용자가 수정하거나 무시할 수 있어야 한다.
- 분석 AI에 쓰이는 데이터 범위와 목적은 약관/개인정보 동의에 명확히 포함한다.

권장 구조:

모바일 앱
-> Supabase Edge Function
-> AI API
-> 결과 반환
-> 앱 또는 Supabase에 저장


6. AI 기능 범위

1차 AI 기능:
- 기록 한 줄 요약
- 기록 태그 추천
- 관련 행복 리스트 추천

2차 AI 기능:
- 오늘의 행복 추천
- 기존 리스트 중 3개 정도 추천
- 추천 이유 한 줄 제공

3차 AI 기능:
- 최근 7일 / 30일 행복 분석
- 자주 등장한 태그 정리
- 행복 유형 비중 분석
- 앞으로 시도해볼 행복 제안

4차 AI 기능:
- 자유 기록을 돕는 질문 생성
- 예: "오늘 다시 떠올리고 싶은 장면은?"
- 예: "오늘 마음이 편해진 순간은?"
- 예: "오늘 작지만 좋았던 일은?"


7. 1층 행복 유형

1층 행복 유형은 사용자에게 직접 보여주는 필터가 아니다.
내부 분석용 데이터로만 사용한다.

1층 행복 유형:

1. 감각적 행복
- 먹기, 자기, 음악 듣기, 여행, 재밌는 영상 보기
- 즐거움, 쾌감, 편안함처럼 직접 느껴지는 행복

2. 성취적 행복
- 시험 통과, 기록 갱신, 돈 벌기, 프로젝트 완료
- 목표, 성장, 성취감에서 오는 행복

3. 관계적 행복
- 가족, 친구, 연인, 동료, 커뮤니티
- 사랑, 소속감, 안정, 친밀감에서 오는 행복

4. 몰입적 행복
- 운동, 게임, 글쓰기, 그림, 코딩, 음악, 요리, 독서, 창작, 연구
- 집중, 몰두, 깊이에서 오는 행복

5. 의미적 행복
- 꿈, 목적, 가치관, 사명, 삶의 이야기, 방향성
- 내가 중요하게 여기는 의미에서 오는 행복

중요한 원칙:
- 하나의 기록이나 리스트 항목은 하나의 유형에만 귀속되지 않는다.
- 행복은 여러 유형이 겹칠 수 있다.
- 따라서 1층 행복 유형은 복수 부여가 가능해야 한다.

권장 방식:
- 한 기록 또는 리스트 항목에 1~3개의 행복 유형을 부여한다.
- 각 유형은 합계 10점이 되도록 가중치를 가진다.

예:

happinessTypes: [
  { type: "감각적 행복", weight: 7 },
  { type: "성취적 행복", weight: 2 },
  { type: "의미적 행복", weight: 1 }
]

분석에서는 이 점수를 누적한다.

예:
- 감각적 행복 70%
- 성취적 행복 20%
- 의미적 행복 10%


8. 2층 태그

2층 태그는 사용자에게 보여지는 태그다.
검색, 필터, 기록 보조, 리스트 탐색에 사용한다.

최종 2층 태그:

상황
- 혼자
- 함께
- 실내
- 실외

조건
- 짧게
- 길게
- 무료
- 유료

상태
- 활동적
- 휴식

감정
- 즐거움
- 편안함
- 설렘
- 뿌듯함
- 위로
- 감동
- 새로움

총 17개 태그다.

UI에서는 전체를 한 번에 노출하기보다, 상황/조건/상태/감정으로 묶어서 보여주는 것이 좋다.

예:

상황: [혼자] [함께] [실내] [실외]
조건: [짧게] [길게] [무료] [유료]
상태: [활동적] [휴식]
감정: [즐거움] [편안함] [설렘] [뿌듯함] [위로] [감동] [새로움]

약관/동의에서 안내할 내용:
- 해피파인더는 저장된 기록과 앱 사용 데이터를 바탕으로 행복 유형, 태그, 패턴, 추천을 분석할 수 있다.
- 분석 결과는 사용자에게 개인화된 행복 분석과 추천을 제공하기 위해 사용된다.
- 기록 작성 화면의 "기록 AI 도움"은 작성 보조 기능이며, 사용자가 기록마다 켜고 끌 수 있다.
- 기록 AI 도움을 꺼도 저장된 기록은 기본 분석 기능의 데이터로 사용될 수 있다.
- 민감한 개인정보나 타인의 개인정보를 기록하지 않도록 안내한다.


9. 태그와 AI의 관계

리스트 항목에는 2층 태그와 1층 행복 유형을 모두 저장한다.

사용자에게 보이는 것:
- 2층 태그

사용자에게 직접 보이지 않는 것:
- 1층 행복 유형과 가중치

예:

{
  id,
  title: "산책하기",
  description: "가볍게 걸으며 몸과 마음을 환기해보세요.",
  tags: ["혼자", "실외", "짧게", "무료", "활동적", "편안함"],
  happinessTypes: [
    { type: "감각적 행복", weight: 5 },
    { type: "몰입적 행복", weight: 3 },
    { type: "의미적 행복", weight: 2 }
  ]
}

기록에도 같은 구조를 적용한다.

{
  id,
  content,
  images,
  linkedItemId,
  tags: ["혼자", "실내", "휴식", "편안함"],
  happinessTypes: [
    { type: "감각적 행복", weight: 8 },
    { type: "의미적 행복", weight: 2 }
  ],
  aiEnabled: true,
  aiSummary,
  createdAt,
  updatedAt
}


10. 검색과 태그 선택

홈 리스트에는 검색 기능과 태그 필터를 넣는다.

검색 대상:
- 행복 제목
- 설명
- 2층 태그

태그 필터:
- 사용자가 태그를 눌러 현재 할 수 있는 행복을 좁힌다.

예:
- 혼자 + 실내 + 짧게
- 함께 + 실외 + 유료
- 휴식 + 편안함
- 활동적 + 뿌듯함

AI는 사용자의 기록 패턴을 바탕으로 적절한 태그를 추천 필터로 제안할 수 있다.

예:
"최근에는 혼자, 실내, 편안함 태그가 자주 보여요. 오늘도 이런 행복을 찾아볼까요?"


11. 분석 화면

분석 화면은 사용자가 자신의 행복 구조를 이해하는 곳이다.
분석 화면은 기록 기능이 어느 정도 잡힌 뒤 2.5단계에서 별도 화면으로 분리해 추가한다.
2단계에서는 기록을 안정화하고, 2.5단계에서 홈 / 기록 / 분석 / 프로필 탭 구조를 완성한다.
단, 2.5단계의 분석 화면은 처음부터 완전한 AI 분석까지 구현하지 않고,
사용자가 앞으로 어떤 분석을 보게 될지 이해할 수 있는 기본 UI와 데이터 표시 구조를 먼저 만든다.

추천 구성:

1. 최근 행복 요약
- AI가 최근 기록을 한두 문장으로 정리
- 예: "최근에는 편안함과 감각적 행복이 자주 나타났어요. 혼자 쉬는 시간이 행복으로 이어지는 흐름이 보여요."

2. 행복 유형 비중
- 1층 행복 유형 가중치를 누적
- 원형 그래프로 표시
- 감각적 / 성취적 / 관계적 / 몰입적 / 의미적 행복 비중 표시

3. 자주 등장한 태그
- 2층 태그 출현 빈도 표시
- 예: 혼자, 실내, 편안함, 휴식

4. AI 추천
- 기존 행복 리스트 중 3~5개 추천
- 추천 이유 한 줄 제공

5. 균형 제안
- "부족하다"는 표현은 피한다.
- 대신 부드럽게 제안한다.
- 예: "이번 주에는 관계적 행복 기록이 적은 편이에요. 부담 없다면 짧은 연락이나 함께하는 시간을 시도해볼 수 있어요."


12. UI/UX 원칙

전체 UI는 기록 부담을 줄이는 방향이어야 한다.

원칙:
- 긴 설명보다 바로 쓸 수 있는 입력 화면을 우선한다.
- 스탬프나 횟수보다 기록 자체를 중심에 둔다.
- AI는 자동 판단자가 아니라 조용한 보조자처럼 느껴져야 한다.
- 사용자는 AI를 끄고 순수 기록만 남길 수 있어야 한다.
- 태그는 너무 많은 칩을 한 화면에 다 보여주지 않는다.
- 기록 작성 화면은 한 줄 기록과 긴 일기를 모두 수용해야 한다.

권장 문구:
- "한 줄이어도 좋고 길게 써도 좋아요."
- "오늘 어떤 순간을 남기고 싶나요?"
- "AI 도움을 받을까요?"
- "이 기록은 AI 분석에서 제외할 수 있어요."


13. 데이터 변경 방향

기존 category 필드는 바로 삭제하지 않는 것이 안전하다.
기존 데이터와 Supabase 구조가 영향을 받을 수 있기 때문이다.

권장:
- 기존 category는 legacy 필드로 유지
- 사용자 UI에서는 숨김
- 새 tags 필드 추가
- 새 happinessTypes 필드 추가
- 새 records 또는 journalRecords 구조 추가

기존 메모 기능은 기록 기능으로 확장할 수 있다.
이미 사진 첨부 기능이 들어갔으므로 기록 기능의 기반으로 활용 가능하다.


14. MVP 구현 순서

1단계: 리스트 구조 정리
- 홈 카테고리 탭 제거
- 길게 누르기 제거
- 스탬프 제거
- 연필 버튼 제거
- 기록하기 버튼을 처음부터 노출
- 즐겨찾기 기능을 "내 행복"으로 리네이밍
- 기존 즐겨찾기 하트 위치를 "내 행복" 위치로 유지
- 홈 화면 플러스 버튼으로 "내 행복 만들기" 진입 추가
- 프로필에는 내가 만든 행복과 내 행복 만들기 기능 유지

2단계: 기록 페이지 추가
- 하단 탭은 홈 / 기록 / 프로필 구조를 유지하고, 분석 탭은 2.5단계에서 추가
- 기록 페이지 추가
- 기록 페이지는 월별 기록 구조로 정리
- 리스트 연결 기록보다 사용자가 직접 남기는 기록 기능을 우선
- 자유 기록 작성 기능 추가
- 사진 첨부 기능 재사용
- 기록 AI 도움 토글 UI는 화면 구조가 안정된 뒤 추가
- Q 버튼과 설정 버튼은 프로필 화면에서만 노출

2.5단계: 분석 화면 뼈대 추가
- 하단 탭을 홈 / 기록 / 분석 / 프로필로 변경
- 분석 화면을 새 탭으로 추가
- 처음에는 AI 호출 없이 저장된 기록 기반의 기본 통계와 빈 상태 UI를 먼저 구성
- 기록이 부족할 때는 "기록이 쌓이면 행복 패턴을 보여드릴게요" 같은 안내 표시
- 최근 기록 수, 자주 등장한 단어/태그, 기록이 많은 월 또는 기간 같은 가벼운 정보부터 표시
- 추후 AI 분석이 들어갈 자리에는 "나의 행복 스타일", "최근 행복 요약", "추천 행복" 영역을 미리 설계
- 프로필 상단의 AI 행복 스타일 요약 카드와 분석 화면 이동 버튼은 이 단계 이후 연결
- 2.5단계의 목적은 분석 기능의 UX 자리와 데이터 흐름을 먼저 만드는 것
- 실제 AI 분석, 행복 유형 가중치, 원형 그래프 고도화는 4~5단계에서 진행

3단계: 태그 시스템 추가
- 2층 태그를 리스트와 기록에 부여
- 홈 검색 기능 추가
- 태그 필터 기능 추가
- 기존 행복 리스트에 태그 데이터 추가

4단계: 분석 데이터 고도화
- 1층 행복 유형과 가중치 데이터 추가
- 기록과 리스트에 happinessTypes 저장
- 2.5단계에서 만든 분석 화면에 원형 그래프 추가
- 자주 등장한 태그 표시
- 기간별 분석, 태그별 흐름, 행복 유형 비중을 실제 데이터로 계산

5단계: AI 연동
- Supabase Edge Function 생성
- 기록 요약, 태그 추천, 행복 유형 가중치 추천
- AI 결과 저장
- 분석 페이지에서 AI 패턴 분석 제공


15. 최종 제품 컨셉

해피파인더는 행복을 정답처럼 알려주는 앱이 아니다.
사용자가 자신의 일상에서 행복을 발견하고, 자유롭게 기록하고,
AI가 그 기록을 바탕으로 "내 행복의 모양"을 천천히 보여주는 앱이다.

정리 문장:

"한 줄이어도, 긴 일기여도 괜찮아요.
해피파인더는 당신의 행복이 어떤 모양인지 천천히 찾아줍니다."
