Happy Finder Tag Combination Plan
작성 기준일: 2026-05-26

목적
- 현재 분석은 2층 수동 태그를 기준으로 사용자의 행복 성향을 보여준다.
- 큰 행복 성향은 4가지 핵심 축으로 16가지 유형을 만든다.
- 비용 태그인 무료/유료는 큰 성향 유형에 포함하지 않고, 별도의 실행 방식 라벨로 뒤에 작게 붙인다.
- 1층 태그는 나중에 AI가 붙었을 때 사용할 상위 성향 태그로 남겨둔다.
- AI가 붙기 전까지 원형 그래프는 사용하지 않고, 4가지 핵심 축과 비용 축을 막대 그래프로 보여준다.


1. 그래프 방향

현재 버전
- 원형 그래프 사용 안 함.
- 4가지 핵심 축을 막대 그래프로 표시.
- 비용 축은 별도 막대 그래프로 표시하되, 큰 성향 유형에는 포함하지 않는다.

예시

관계
혼자 ---------------- 함께
30%                   70%

장소
실내 ---------------- 실외
65%                   35%

시간
짧게 ---------------- 길게
40%                   60%

행동
활동적 -------------- 휴식
45%                   55%

비용
무료 ---------------- 유료
80%                   20%

나중에 AI 도입 후
- 1층 AI 태그가 붙으면 원형 그래프를 다시 사용한다.
- 원형 그래프는 사용자의 상위 행복 성향 분포를 보여주는 용도로 쓴다.
- 2층 수동 태그는 계속 막대 그래프로 보여준다.


2. 태그 축

큰 성향을 만드는 4가지 핵심 축

1. 관계
- 혼자
- 함께

2. 장소
- 실내
- 실외

3. 시간
- 짧게
- 길게

4. 행동
- 활동적
- 휴식

별도 실행 방식 축

5. 비용
- 무료
- 유료


3. 비용 라벨

비용 라벨은 16가지 큰 성향 이름 뒤에 작게 붙인다.

무료 우세 -> 비소비형
- 돈을 쓰지 않거나, 비용 부담이 적은 행복에서 만족을 얻는 경향.
- 예: "자기 루틴 실행형 · 비소비형"

유료 우세 -> 소비형
- 돈을 쓰는 경험, 보상, 계획된 소비에서 행복을 얻는 경향.
- 예: "자기 루틴 실행형 · 소비형"

무료/유료가 비슷함 -> 균형형
- 비용이 행복의 핵심 기준이 아니거나, 무료/유료 행복을 균형 있게 사용하는 경향.
- 예: "자기 루틴 실행형 · 균형형"


4. 16가지 행복 성향 유형

1. 혼자 + 실내 + 짧게 + 활동적 -> 자기 루틴 실행형
- 혼자 있는 실내에서 짧고 분명한 행동을 통해 활력을 얻는 유형.

2. 혼자 + 실내 + 짧게 + 휴식 -> 미니 회복 루틴형
- 혼자 있는 실내에서 짧게 쉬며 빠르게 마음과 컨디션을 회복하는 유형.

3. 혼자 + 실내 + 길게 + 활동적 -> 심층 몰입 실행형
- 혼자 실내에서 오래 집중하고 무언가를 해내며 만족을 얻는 유형.

4. 혼자 + 실내 + 길게 + 휴식 -> 깊은 안정 회복형
- 혼자 실내에서 긴 시간을 보내며 안정과 회복을 얻는 유형.

5. 혼자 + 실외 + 짧게 + 활동적 -> 단기 환기 실행형
- 짧게 밖으로 나가 움직이며 기분과 흐름을 바꾸는 유형.

6. 혼자 + 실외 + 짧게 + 휴식 -> 고요한 산책 회복형
- 혼자 짧게 밖에 머물며 바람, 햇빛, 거리감으로 마음을 정리하는 유형.

7. 혼자 + 실외 + 길게 + 활동적 -> 독립 탐색 성장형
- 혼자 밖에서 오래 움직이며 새로운 자극과 자기 확장을 얻는 유형.

8. 혼자 + 실외 + 길게 + 휴식 -> 느린 여정 회복형
- 혼자 밖에서 긴 시간을 보내며 여유와 회복을 얻는 유형.

9. 함께 + 실내 + 짧게 + 활동적 -> 가벼운 실내 교류형
- 실내에서 사람들과 짧고 활기 있게 교류하며 기분을 올리는 유형.

10. 함께 + 실내 + 짧게 + 휴식 -> 짧은 안정 교류형
- 실내에서 짧은 대화나 만남으로 관계의 안정감을 얻는 유형.

11. 함께 + 실내 + 길게 + 활동적 -> 공동 몰입 실행형
- 사람들과 실내에서 오래 활동하며 함께 무언가를 만들거나 즐기는 유형.

12. 함께 + 실내 + 길게 + 휴식 -> 깊은 대화 안정형
- 실내에서 사람들과 오래 머물며 대화, 휴식, 유대감을 쌓는 유형.

13. 함께 + 실외 + 짧게 + 활동적 -> 즉흥 활력 교류형
- 짧은 외출이나 활동을 통해 사람들과 활력을 주고받는 유형.

14. 함께 + 실외 + 짧게 + 휴식 -> 가벼운 동행 회복형
- 함께 짧게 밖에 머물며 부담 없이 회복하는 유형.

15. 함께 + 실외 + 길게 + 활동적 -> 공동 탐험 활력형
- 함께 밖에서 오래 움직이며 경험과 에너지를 확장하는 유형.

16. 함께 + 실외 + 길게 + 휴식 -> 긴 동행 회복형
- 함께 긴 시간을 보내며 여유, 안정감, 기억을 쌓는 유형.


5. 최종 유형 표기 방식

형식
- 큰 성향 유형 · 비용 라벨

예시
- 자기 루틴 실행형 · 비소비형
- 심층 몰입 실행형 · 소비형
- 공동 탐험 활력형 · 균형형

판단 방식
- 관계, 장소, 시간, 행동 4개 축에서 더 높은 쪽을 골라 16가지 큰 유형 중 하나를 정한다.
- 비용 축은 무료/유료 중 더 높은 쪽을 보고 별도 라벨로 붙인다.
- 무료와 유료가 비슷하면 균형형으로 표시한다.
- 동률이면 최근 기록 또는 공감 데이터를 우선한다.
