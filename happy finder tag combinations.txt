Happy Finder Tag Combination Guide
작성 기준일: 2026-05-26

목적
- 분석 기능에서 2차 태그 조합을 보고 사용자의 행복 성향을 설명하기 위한 기준표다.
- 현재 단계에서는 AI 없이도 해석 가능한 단순한 태그 구조를 우선한다.
- 감정은 사람마다 다르게 느낄 수 있으므로, 현재 MVP 태그에서는 제외한다.
- 추후 AI가 붙으면 감정은 사용자가 고르는 태그가 아니라 기록 내용과 행동 맥락을 보고 AI가 해석하는 영역으로 넘긴다.


1. 5가지 태그 분류

현재 MVP에서는 태그를 아래 5가지 기준으로 분류한다.

1. 관계
- 혼자
- 함께

2. 장소
- 실내
- 실외

3. 시간
- 짧게
- 길게

4. 비용
- 무료
- 유료

5. 행동 상태
- 활동적
- 휴식

총 태그 수: 10개

제거할 태그
- 즐거움
- 편안함
- 설렘
- 뿌듯함
- 위로
- 감동
- 새로움

감정 태그를 제거하는 이유
- 같은 활동이어도 사용자가 느끼는 감정은 사람마다 다르다.
- 예를 들어 산책은 어떤 사람에게는 편안함이고, 어떤 사람에게는 성취감이고, 어떤 사람에게는 새로움일 수 있다.
- 감정을 사용자가 직접 고르게 하면 태그 선택이 어려워지고, 분석 결과도 주관적으로 흔들릴 수 있다.
- 감정은 태그보다 기록 내용, 메모 문장, 공감 행동, 반복 패턴을 보고 해석하는 편이 더 자연스럽다.
- 따라서 감정은 현재 MVP에서는 제외하고, AI 도입 시 분석 문장으로 풀어내는 영역으로 둔다.

5가지 분류를 유지하는 이유
- 혼자/함께: 행복이 개인 중심인지 관계 중심인지 판단할 수 있다.
- 실내/실외: 행복이 안정된 공간 중심인지 외부 경험 중심인지 판단할 수 있다.
- 짧게/길게: 행복이 짧은 루틴인지 긴 몰입인지 판단할 수 있다.
- 무료/유료: 행복이 부담 없는 일상형인지 계획된 보상형인지 판단할 수 있다.
- 활동적/휴식: 행복이 에너지 발산형인지 회복형인지 판단할 수 있다.


2. 기본 판단 원칙

3개 태그를 무조건 하나의 유형으로 고정하지 않는다.

이유
- 현재 태그는 최대 3개까지 붙지만, 사용자가 항상 의미 있는 3개 조합을 고르는 것은 아니다.
- 초반 데이터가 적을 때 3개 조합만 보면 유형이 너무 잘게 쪼개진다.
- 2개 조합으로 큰 성향을 잡고, 3번째 태그는 세부 해석을 보강하는 편이 안정적이다.

추천 방식
- 1차 판단: 핵심 2개 태그 조합으로 기본 유형을 정한다.
- 2차 판단: 3번째 태그가 반복되면 세부 성향이나 설명 문장에 반영한다.
- 3차 판단: 무료/유료, 짧게/길게는 사용자가 행복을 실행하는 방식으로 해석한다.
- 4차 판단: 감정은 태그로 판단하지 않고, 나중에 AI가 기록 문장과 메모를 보고 해석한다.

예시
- 혼자 + 실내 -> 자기 몰입형 행복
- 혼자 + 실내 + 길게 -> 자기 몰입형 행복 중에서도 오래 집중하며 회복하는 경향
- 혼자 + 실내 + 무료 -> 부담 없이 반복 가능한 개인 루틴에서 행복을 얻는 경향


3. 핵심 2태그 조합

혼자 + 실내 -> 자기 몰입형 행복
- 혼자 있는 실내 시간에서 마음을 정리하고 자기 속도를 회복하는 유형.
- 취미, 독서, 기록, 정돈, 콘텐츠 감상처럼 자기만의 공간에서 안정적으로 행복을 찾는다.

혼자 + 실외 -> 독립 탐색형 행복
- 혼자 밖으로 나가 새로운 장면을 만나며 에너지를 회복하는 유형.
- 산책, 카페 이동, 전시 관람, 혼자 여행처럼 외부 환경에서 자기 리듬을 찾는다.

함께 + 실내 -> 친밀 교류형 행복
- 가까운 사람과 안정된 공간에서 행복을 느끼는 유형.
- 대화, 식사, 게임, 영화, 홈파티처럼 관계의 밀도를 높이는 활동과 잘 맞는다.

함께 + 실외 -> 공동 경험형 행복
- 사람들과 밖에서 경험을 나누며 행복을 느끼는 유형.
- 나들이, 공연, 운동, 맛집 탐방처럼 함께 기억을 만드는 활동과 잘 맞는다.

혼자 + 짧게 -> 개인 회복 루틴형 행복
- 짧은 혼자만의 행동으로 빠르게 기분을 정리하는 유형.
- 커피 한 잔, 음악 한 곡, 짧은 산책처럼 일상 속 작은 회복에 강하다.

혼자 + 길게 -> 심층 자기몰입형 행복
- 혼자 충분한 시간을 확보했을 때 깊게 몰입하고 만족을 얻는 유형.
- 글쓰기, 공부, 독서, 정리, 긴 산책처럼 오래 이어지는 활동과 잘 맞는다.

함께 + 짧게 -> 가벼운 교류형 행복
- 부담 없는 짧은 만남이나 연락에서 기분이 좋아지는 유형.
- 짧은 대화, 메시지, 간단한 식사, 잠깐의 산책과 잘 맞는다.

함께 + 길게 -> 관계 축적형 행복
- 사람들과 오래 시간을 보내며 관계와 기억이 쌓이는 데서 행복을 느끼는 유형.
- 여행, 긴 대화, 함께하는 취미, 하루 일정 공유와 잘 맞는다.

실내 + 짧게 -> 실내 재정비형 행복
- 짧은 실내 행동으로 컨디션을 정리하는 유형.
- 책상 정리, 차 마시기, 짧은 스트레칭, 방 분위기 바꾸기와 잘 맞는다.

실내 + 길게 -> 집중 생활형 행복
- 실내에서 오래 머물며 생활의 밀도와 완성도를 높이는 유형.
- 요리, 공부, 취미 제작, 정리, 콘텐츠 몰입과 잘 맞는다.

실외 + 짧게 -> 환기 전환형 행복
- 짧게 밖으로 나가 기분을 바꾸는 데서 행복을 느끼는 유형.
- 편의점 다녀오기, 동네 산책, 햇빛 쐬기처럼 가벼운 외출과 잘 맞는다.

실외 + 길게 -> 탐색 확장형 행복
- 밖에서 충분한 시간을 보내며 새로운 자극과 시야를 얻는 유형.
- 여행, 전시, 긴 산책, 새로운 장소 방문과 잘 맞는다.

무료 + 짧게 -> 일상 소확행형 행복
- 비용과 시간이 거의 들지 않는 작은 행동에서 행복을 자주 발견하는 유형.
- 물 마시기, 창문 열기, 음악 한 곡 듣기처럼 반복 가능한 행복과 잘 맞는다.

무료 + 길게 -> 저비용 몰입형 행복
- 비용 부담 없이 오래 이어지는 활동에서 만족을 얻는 유형.
- 독서, 산책, 공부, 정리, 긴 대화처럼 돈보다 시간과 몰입이 중요한 행복과 잘 맞는다.

유료 + 짧게 -> 즉시 보상형 행복
- 작은 소비나 짧은 유료 경험으로 기분 전환을 얻는 유형.
- 커피, 간식, 작은 선물, 짧은 유료 콘텐츠처럼 즉각적인 만족과 잘 맞는다.

유료 + 길게 -> 계획 보상형 행복
- 시간과 비용을 들여 준비한 경험에서 행복을 느끼는 유형.
- 여행, 공연, 클래스, 좋은 식사처럼 기대와 보상이 분명한 활동과 잘 맞는다.

활동적 + 혼자 -> 자기 주도 성장형 행복
- 혼자 움직이고 시도하며 스스로 해냈다는 감각에서 행복을 느끼는 유형.
- 운동, 공부, 만들기, 개인 프로젝트와 잘 맞는다.

활동적 + 함께 -> 사회적 활력형 행복
- 사람들과 함께 움직이고 반응을 주고받으며 에너지를 얻는 유형.
- 운동, 모임, 여행, 체험 활동, 이벤트와 잘 맞는다.

휴식 + 혼자 -> 내면 회복형 행복
- 혼자 쉬며 컨디션과 마음을 회복하는 데서 행복을 느끼는 유형.
- 낮잠, 음악 듣기, 조용한 정리, 혼자 쉬기와 잘 맞는다.

휴식 + 함께 -> 관계 안정형 행복
- 사람들과 편안하게 머무르는 시간에서 행복을 느끼는 유형.
- 함께 쉬기, 오래 이야기하기, 산책, 가벼운 식사와 잘 맞는다.


4. 3태그 세부 조합 예시

혼자 + 실내 + 길게 -> 심층 몰입형 행복
- 혼자만의 공간에서 오래 집중하며 자기 세계를 깊게 만드는 유형.

혼자 + 실내 + 짧게 -> 짧은 회복 루틴형 행복
- 혼자 있는 짧은 실내 루틴으로 빠르게 컨디션을 회복하는 유형.

혼자 + 실외 + 길게 -> 독립 여정형 행복
- 혼자 밖에서 충분히 시간을 보내며 생각과 감각을 확장하는 유형.

혼자 + 실외 + 짧게 -> 환기 산책형 행복
- 짧게 밖으로 나가 기분과 흐름을 바꾸는 데서 행복을 느끼는 유형.

함께 + 실내 + 길게 -> 깊은 유대형 행복
- 익숙한 공간에서 사람들과 오래 머물며 관계의 깊이를 느끼는 유형.

함께 + 실내 + 짧게 -> 가벼운 친밀형 행복
- 짧고 부담 없는 만남이나 대화에서 안정적인 행복을 얻는 유형.

함께 + 실외 + 길게 -> 공유 경험형 행복
- 밖에서 함께 긴 경험을 만들며 기억과 이야기를 쌓는 유형.

함께 + 실외 + 짧게 -> 즉흥 교류형 행복
- 짧은 외출이나 만남으로 활력을 얻는 유형.

혼자 + 활동적 + 길게 -> 자기 훈련형 행복
- 혼자 오래 움직이거나 몰입하며 스스로를 발전시키는 데서 행복을 느끼는 유형.

혼자 + 휴식 + 짧게 -> 미니 회복형 행복
- 짧은 혼자만의 휴식으로 빠르게 마음을 정리하는 유형.

함께 + 활동적 + 실외 -> 활력 공유형 행복
- 밖에서 함께 움직이며 에너지를 나누는 유형.

함께 + 휴식 + 실내 -> 편안한 유대형 행복
- 실내에서 함께 쉬며 관계의 안정감을 느끼는 유형.

무료 + 짧게 + 혼자 -> 부담 없는 개인 루틴형 행복
- 돈과 시간을 크게 쓰지 않고 혼자 반복 가능한 작은 행복을 찾는 유형.

무료 + 길게 + 실외 -> 저비용 탐색형 행복
- 비용 부담 없이 밖에서 오래 머물며 환기와 탐색을 즐기는 유형.

유료 + 짧게 + 함께 -> 가벼운 보상 교류형 행복
- 짧은 소비 경험을 함께 나누며 기분 전환을 얻는 유형.

유료 + 길게 + 함께 -> 계획된 경험 공유형 행복
- 비용과 시간을 들인 경험을 함께하며 기억을 쌓는 유형.


5. 감정 해석은 어떻게 다룰 것인가

현재 MVP
- 감정 태그는 사용자가 직접 선택하지 않는다.
- 분석은 관계, 장소, 시간, 비용, 행동 상태 태그를 기준으로 한다.
- 감정 표현은 분석 문장 안에서 단정하지 않고 부드럽게 추정한다.

AI 도입 이후
- 기록 제목과 내용, 행복 메모, 공감한 행복, 반복 패턴을 AI가 보고 감정을 추론한다.
- 예: "위로가 필요한 행복", "성취를 통해 살아나는 행복", "관계에서 안정되는 행복"처럼 문장으로 표현한다.
- 감정은 태그가 아니라 리포트의 해석 품질을 높이는 요소로 사용한다.


6. 구현 우선순위

1순위
- 기존 감정 태그를 제거했을 때 현재 행복 데이터와 UI에 어떤 영향이 있는지 확인한다.
- 기존 데이터에 저장된 감정 태그는 분석에서 제외하거나 마이그레이션한다.

2순위
- 새 태그 목록을 코드에 반영한다.
- 관계, 장소, 시간, 비용, 행동 상태 그룹으로 UI를 정리한다.

3순위
- 분석 문장 생성 로직에서 2태그 기본 유형을 먼저 판단한다.
- 3번째 태그는 세부 설명, 장점, 주의점, 추천 행동에 반영한다.

4순위
- 추천 행복은 사용자가 자주 고른 태그와 가까우면서 아직 기록/공감하지 않은 행복을 우선으로 보여준다.

5순위
- AI 도입 후에는 감정 해석을 태그가 아니라 기록 문장 기반으로 추가한다.
