Happy Finder New Plan
최근 업데이트: 2026-06-04

1. 현재 제품 방향

Happy Finder는 바쁜 일상 속에서 지나치기 쉬운 작은 행복을 발견하고, 직접 기록하고, 다른 사람의 행복에 공감하며, 나의 행복 패턴을 돌아보는 앱으로 간다.

핵심 방향
- AI는 출시 직전 버전에 바로 넣지 않는다.
- AI 없이도 홈, 행복 리스트, 기록, 메모, 공감, 분석이 자연스럽게 이어지는 앱을 먼저 출시한다.
- 출시 후 사용자 반응과 실제 사용 데이터를 보고 AI 기능을 붙인다.
- 앱의 핵심은 많은 기능이 아니라 "행복을 발견하고 기록하는 흐름"이다.
- 문장 톤은 "이렇게 하면 행복합니다"보다 "나는 이렇게 해보니 행복했어요"에 가깝게 유지한다.

2. 현재 구현 기준

홈
- 오늘의 행복 영역을 통해 기록을 자연스럽게 유도한다.
- 기본 행복 리스트와 사용자가 만든 행복을 카드로 보여준다.
- 검색, 태그 필터, 빈 상태 문구를 제공한다.
- 리스트 카드에는 이미지, 제목, 짧은 설명, 태그, 메모/공감 상태를 간결하게 보여준다.
- 기본 행복 리스트 일부 항목에는 생성 이미지 썸네일을 적용하기 시작했다.

기록
- 자유 기록 작성, 사진 첨부, 카메라/앨범, 사진 저장 기능을 제공한다.
- 일/월/모두 보기 구조를 사용한다.
- 기록 삭제처럼 실제 데이터가 사라지는 동작에는 확인 모달을 사용한다.

행복 메모
- 행복 리스트 상세에서 메모를 남길 수 있다.
- 메모가 있는 항목은 리스트 밖에서도 노트 아이콘으로 상태를 보여준다.
- 행복 메모는 기록 화면 안에서 별도 탭으로 확인한다.

행복 만들기
- 사용자가 직접 행복 항목을 만들 수 있다.
- 이미지가 없으면 앱 기본 이미지로 대체된다는 확인 흐름을 둔다.
- 태그는 관계, 장소, 시간, 행동 4개 축에서 각각 1개씩 선택한다.
- 태그는 행복 리스트에만 적용하고 자유 기록에는 붙이지 않는다.

공감
- 공감은 좋아요/랭킹이 아니라 "나도 이 마음을 알아요"에 가까운 따뜻한 반응으로 둔다.
- 공감한 항목은 프로필에서 확인할 수 있다.
- 리스트 밖에서는 작은 웃는 아이콘으로 공감 상태만 보여준다.
- 사용자가 만든 공개 행복에 누군가 공감하면 알림을 보낸다.

분석
- AI 없이 태그, 기록, 메모, 공감, 즐겨찾기 데이터를 기반으로 분석을 보여준다.
- 현재 분석은 관계, 장소, 시간, 행동 4개 태그 축의 비율을 막대 그래프로 보여준다.
- 4개 축 조합으로 16가지 행복 성향 유형을 보여준다.
- 분석 단계는 데이터 개수뿐 아니라 4개 축이 얼마나 고르게 쌓였는지도 함께 본다.
- 추천 행복은 사용자의 태그 흐름을 기준으로 보여준다.
- 주간 행복 분석은 날짜별 활동량을 꺾은선 그래프로 보여준다.

프로필
- 즐겨찾기, 내가 만든 행복, 내가 공감한 행복을 확인한다.
- 계정 로그인 기반 사용을 원칙으로 한다.
- 게스트 사용 흐름은 제거하고 계정 데이터 중심으로 유지한다.

웹
- 앱 디자인과 어울리는 소개/문의/법적 정보 페이지를 제공한다.
- 앱의 현재 기능과 맞게 문구를 정리한다.
- 이용약관, 개인정보 처리방침, 문의/피드백 경로를 출시 전 다시 확인한다.

3. 태그와 유형 정책

현재 태그 축
- 관계: 혼자 / 함께
- 장소: 실내 / 실외
- 시간: 짧게 / 길게
- 행동: 활동적 / 휴식

정책
- 하나의 행복에는 4개 축에서 각각 1개씩 총 4개 태그가 붙는다.
- 무료/유료 태그는 제거한다.
- 감정 태그는 사람마다 다르게 느낄 수 있으므로 현재 수동 태그에서는 제외한다.
- AI 도입 후에는 감정과 맥락을 기록 문장과 행동 패턴으로 해석한다.

4. 출시 전 남은 확인

필수 QA
- 앱 설치 후 회원가입/로그인/로그아웃 흐름 확인
- 기록 작성, 수정, 삭제 확인
- 행복 메모 작성, 수정, 삭제 확인
- 행복 만들기, 태그 선택, 이미지 대체 흐름 확인
- 공감, 즐겨찾기, 공유 흐름 확인
- 분석 화면 데이터 반영 확인
- Android 실제 기기에서 카메라/앨범 권한 확인
- AAB 최신화 후 Android Studio와 콘솔 업로드 파일 확인

법적/스토어 체크
- 만 14세 이상 동의 문구 확인
- 이용약관 동의 확인
- 개인정보 수집 및 이용 동의 확인
- 마케팅 정보 수신 동의 확인
- 개인정보 처리방침 최신화
- 앱 설명, 스크린샷, 그래픽 이미지, 문의 경로 확인
- Google Play Console 및 iOS App Store Connect 정보 확인

5. AI 도입 후 계획

AI 기능 후보
- 기록과 메모 문장을 기반으로 감정/맥락 분석
- 행복 목표 기능
- 사용자가 더 많이 행복해질 수 있는 행동 제안
- 줄이면 좋은 행동과 늘리면 좋은 행동 추천
- 태그 자동 추천 및 자동 분류
- 더 정교한 월간/전체 분석 리포트

AI 도입 조건
- 현재 비AI 버전 출시 후 실제 사용 반응을 확인한다.
- 어떤 데이터가 충분히 쌓이는지 확인한다.
- 사용자가 분석 기능을 실제로 쓰는지 확인한다.
- 비용 대비 효과가 있는 기능부터 붙인다.

6. 협업 원칙

- 사용자의 목적이 명확하면 바로 실행한다.
- 목적이나 방향이 애매하면 짧게 확인 질문을 한다.
- 사용자가 놓칠 수 있는 UX, 출시, 법적, 운영 관점은 먼저 짚어준다.
- 사용자가 만든 변경분은 임의로 되돌리지 않는다.
- 비밀값, 토큰, 환경변수 값은 출력하지 않는다.
- 커밋/푸시는 사용자가 요청했을 때 진행한다.
